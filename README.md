# Vita PNG Game

Tiny native PS Vita homebrew test game.

- Left stick: move
- Collect the yellow square
- Avoid the red square
- X: restart after death
- START: quit

## Automatic build

Every push to `main` runs GitHub Actions and produces a `VitaPNGGame.vpk` artifact.

Open the repo's **Actions** tab, open the latest **Build Vita VPK** run, then download the `VitaPNGGame-VPK` artifact.
